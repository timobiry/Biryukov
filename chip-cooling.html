High-Heat-Flux Chip Cooling

Two-Phase Cooling & SiC Module Packaging

Overview

This project focused on the development and testing of an experimental two-phase cooling system designed for high heat flux applications, specifically targeting Silicon Carbide (SiC) power modules.


Key Contributions

  • Performed Transient Dual Interface Measurements (TDIM) to evaluate SiC power module thermal impedance.
  • Processed transient thermal measurement data using Python to extract thermal resistance characteristics.
  • Assisted in power electronics module fabrication, aligning with stringent ARPA-E project parameters.
